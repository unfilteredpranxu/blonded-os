# Blonded OS sequential roadmap

- **M00 ACTIVE:** true physical-host audit, graphics backend feasibility, clean idle and baseline services; unresolved questions report.
- **M01:** reproducible OS distribution design, build harness and package specifications.
- **M02:** first bootable Arch-derived Blonded OS live image with basic terminal/login and rollback path.
- **M03:** minimal Rust custom window manager proof (window focus/close/resize/placement).
- **M04:** Rust compositor feasibility (background opacity, blur, GPU/CPU fallback, measured frame times).
- **M05:** native Rust desktop shell (dock, launcher, notifications, panels, settings).
- **M06:** Rust scene runtime (pixel waves, ASCII rain, adaptive motion, safe asset loading).
- **M07:** unified live theme engine and per-window overrides.
- **M08:** install/update/recovery/audio/network/input integration.
- **M09:** packaged lightweight Rust utilities and app compatibility.
- **M10:** experimental Rust browser evaluation and reliable fallback.
- **M11:** supported Discord access integration.
- **M12:** original Rust music player with authorized service access where technically available.
- **M13:** physical acceptance testing, boot ISO/recovery tests, low-RAM/latency tuning and release.

Never advance autonomously. Each milestone requires evidence and user review.
